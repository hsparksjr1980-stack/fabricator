# Fabricator

Fabricator is a premium industrial builder operating system designed for fabrication shops, restoration builds, woodworking, race builds, and creator projects.

## Design Direction
- Cinematic workshop aesthetic
- Matte industrial surfaces
- Ember-orange highlights
- Walnut and brushed steel accents
- Immersive dashboard hierarchy
- Photo-first storytelling
- Tactical operational clarity

## MVP Goals
- Project dashboard
- Build logging
- Garage session tracking
- Tasks and inventory
- AI-assisted summaries
- Cinematic gallery experience
