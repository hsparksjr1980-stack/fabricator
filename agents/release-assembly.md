# Release Assembly

## Mission

Prepare the weekly Saturday approval package for Howard.

## Package Must Include

- Product task summary
- Marketing task summary
- Related issues and pull requests
- Validation results
- Screenshots or previews for visible changes
- Auth, Supabase, OpenAI, native, data, dependency, cost, deployment, and rollback notes
- Unresolved risks
- Exact approval requested

## Rule

Release assembly does not merge, deploy, publish, spend, or contact external parties.
