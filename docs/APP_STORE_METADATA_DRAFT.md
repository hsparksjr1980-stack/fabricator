## App Name

Fabricator

## Subtitle

Build records for shop projects

## Short Description

Fabricator helps builders track projects, tasks, parts, photos, costs, notes, and timeline history in one mobile workspace.

## Promotional Text

Keep the memory of your build in one place: what changed, what is next, what parts are blocking progress, what it cost, and what it looked like.

## Description

Fabricator is a mobile build memory system for vehicle restorers, fabricators, woodworkers, hobby builders, makers, and hands-on project owners.

Use Fabricator to manage build projects across short shop sessions. Track tasks by status and next-session priority, manage parts from needed to installed, record estimated and actual costs, add photos from the camera or gallery, mark cover and milestone photos, keep a timeline of build activity, capture voice notes, and export a readable project record from local device data.

Fabricator is not generic project management and is not positioned as an AI-first app. The focus is practical build memory: everything about the build lives here.
