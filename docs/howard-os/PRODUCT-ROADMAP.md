# Product Roadmap

## Roadmap Principles

Prioritize the work that makes Fabricator more useful in a real garage or shop before adding broad platform features.

## Near-Term Product Themes

- Make project setup and reopening fast on mobile.
- Improve tasks, parts, costs, photos, and activity history as one connected workflow.
- Keep budget visibility simple and understandable.
- Improve local persistence reliability before activating cloud synchronization.
- Use advisor features as structured helpers, not a constant chatbot.

## Later Themes

- Cloud project database synchronization.
- Production file storage and uploads.
- Sharing or collaboration, only after single-user workflows are solid.
- Exports or build books for resale records.
- Paid tiers and lifetime purchase flow after pricing approval.

## Not A Priority Without Approval

- Enterprise shop management.
- Complex team permissions.
- Expensive AI-first workflows.
- Production native signing changes.
- Real cloud sync activation.
