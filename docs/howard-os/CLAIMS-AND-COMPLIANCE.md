# Claims And Compliance

All public-facing claims must be factual and supported by repository evidence or approved product records.

## Do Not Claim

- Cloud sync is fully live.
- Collaboration is live.
- Production file uploads are live.
- Every advisor provider is live.
- AI is fully live beyond verified capabilities.
- Guaranteed time savings.
- Guaranteed cost savings.
- Guaranteed completion.
- Professional engineering certification.
- Safety certification.
- A placeholder or mock is production-ready.

## Allowed With Care

- Fabricator is mobile-first.
- Fabricator supports local project tracking.
- Fabricator includes Supabase account signup, sign-in, password reset, and session persistence.
- Fabricator includes project, task, parts, photo, activity, budget, advisor UI, and voice transcription paths.

## Marketing Completion Standard

A marketing task is ready only when a complete deliverable exists, factual review passes, brand review passes, claims review passes, editorial review passes, SEO review is completed where applicable, distribution assets are included, duplication is checked, nothing has been published or sent, and risks and assumptions are documented.
