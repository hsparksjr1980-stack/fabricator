# Brand Voice

## Brand Traits

- Industrial
- Practical
- Trustworthy
- Mobile-first
- Builder-focused
- Affordable

## Voice

Fabricator should sound useful, direct, grounded, and respectful of hands-on work.

Use plain language. Avoid inflated productivity promises and enterprise jargon.

## Preferred Framing

- Build memory
- Project history
- Parts visibility
- Shop-ready notes
- Photo documentation
- Budget awareness
- Next-session clarity

## Avoid

- Claiming guaranteed outcomes.
- Overstating AI.
- Making the product sound like corporate project management.
- Turning useful features into hype.
